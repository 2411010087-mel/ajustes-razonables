# D0 – Documento base

## Problema en una frase
La Oficina de Bienestar Universitario recibe las solicitudes de ajustes razonables por correo, WhatsApp y papel, y por eso se pierden, no se sabe cuáles están pendientes y no se puede generar el reporte semestral.

## Tipos de usuario
1. **Estudiante con discapacidad:** registra su solicitud de ajuste para una asignatura.
2. **Personal de la Oficina de Bienestar:** registra estudiantes, evalúa solicitudes y cambia su estado.
3. **Docente:** necesita saber qué ajuste le corresponde a cada estudiante de su curso.

## Requisitos funcionales
1. El sistema debe permitir registrar a un estudiante con su tipo de discapacidad y el número del documento que la acredita (CONADIS o certificado médico), sin adjuntos.
2. El sistema debe permitir registrar una solicitud de ajuste razonable para una asignatura, indicando el tipo de ajuste.
3. El sistema debe permitir a la oficina cambiar el estado de la solicitud (recibida, evaluada, aprobada, rechazada con motivo, implementada).
4. El sistema debe listar las solicitudes pendientes por estudiante y por asignatura.
5. El sistema debe mostrar el total de solicitudes por tipo de ajuste y por estado, para el reporte semestral.

## Requisitos no funcionales
1. **Accesibilidad:** el formulario debe poder usarse solo con teclado y ser leído por un lector de pantalla (etiquetas en cada campo, errores asociados al campo, buen contraste).
2. **Protección de datos personales:** solo se guardan los datos necesarios, sin adjuntos, y las consultas a la base de datos deben evitar inyección SQL.
